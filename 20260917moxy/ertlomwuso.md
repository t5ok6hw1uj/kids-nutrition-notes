# 你可以考虑从人工授精（IUI）开始

> 更新时间：2026-09-17 (UTC+8)

**宫腔内人工授精（IUI）是什么？**宫腔内人工授精（intrauterine insemination,IUI）指将精子通过非性交方式注入女性生殖道内，使其受孕的一种技术。IUI常规流程为：将精液洗涤处理后，去除精浆，取0.3-0.5ml精子悬浮液，在女方排卵期间，通过导管经宫颈注入宫腔内。IUI是一种相对经济、安全、应用范围广的辅助生殖技术。IUI接近自然受孕的助孕手段，相对于“试管婴儿”，费用低，耗时短。

**什么情况适合做IUI？**

- **男方因素：**
1.精液异常：如轻度或中度少弱畸精子症、精液液化时间长或不液化。2.性功能障碍：存在性交困难，精子不能进入阴道的解剖异常，如严重尿道下裂、逆行射精等。3.精神、心理或神经因素导致的性交不能、不射精等。4.免疫性不育：如感染、创伤等导致血睾屏障损伤，诱发自身免疫抗体产生。
- **女方因素：**
1.盆腔因素：轻、中度子宫内膜异位症，双侧输卵管通畅或一侧输卵管通畅。2.宫颈因素：子宫颈狭窄、粘连等。3.排卵障碍：如多囊卵巢综合征患者3-6个促排卵指导试孕周期未孕。4.不明原因不孕、年龄＜38岁、卵巢功能正常。

**IUI流程**

- **完善检查**
1.女方月经第2-3天空腹抽血检查+胸片+心电图；2.女方月经干净3-7天不同房完善子宫输卵管造影（已查带造影结果）及经净后检查项目；3.男方男科就诊完善检查。
- **建档**
1.带齐所有检查结果门诊看结果；2.夫妇双方有效期内身份证、结婚证原件及复印件护士站审核，并随时携带；根据医嘱适时建档（建病历）.
- **卵泡监测**
1.自然周期：月经第10-12天开始B超监测排卵。2.促排卵周期：月经第3-5天开始促排卵，月经10-12天开始监测卵泡。

**IUI步骤**

1.如女方需诱导排卵者至注射室注射药物，后夫妇双方至西区5楼生殖手术室准备IUI。2.男方取精室采集精液，交实验室处理精液，女方适度憋尿，大约1-2小时精液处理合格后通知女方进入手术室。3.IUI操作需使用窥阴器扩开阴道，暴露宫颈，擦拭阴道分泌物，操作带来轻微不适，可以忍受，患者应避免过度紧张，医生将人工授精导管从宫颈外口缓慢插至宫腔，缓慢推注处理后的精子悬液，整个过程2-3分钟。4.术后女方可排尿，无不适即可离院，无需卧床，可以正常生活和工作。5.女方排卵后给予口服黄体酮或地屈孕酮黄体支持治疗。
**随访**

IUI术后14天，查血hCG确定是否怀孕。如怀孕，继续黄体支持治疗，半月后复查B超；如未孕，下一月经周期继续IUI助孕治疗或与医生沟通下一步助孕方案。

IUI操作简便，患者痛苦小、花费少、并发症发生率低，是目前治疗不孕症常用的辅助生殖技术之一，需要的朋友们具体事宜可以来生殖中心咨询医生，在医生建议下选择适合自己的助孕方式！
